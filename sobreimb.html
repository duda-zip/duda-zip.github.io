IMB Educação.

Uma plataforma de ensino construída do zero.

O IMB Educação é uma plataforma de cursos online que começa pela Radiologia e foi planejada para receber outras áreas da Medicina. Estou desenvolvendo o projeto para um cliente, com identidade visual própria e autonomia para vender e administrar os cursos.

HTMLCSSJavaScriptPHPLaravelMySQLGit/GitHub
01 / A PLATAFORMA

Como o IMB foi pensado.

Site público

Página inicial, páginas de cursos, blog e contato. O fluxo também prevê login, cadastro e recuperação de senha.

Área do aluno

O painel planejado reúne cursos adquiridos, aulas em vídeo, acompanhamento de progresso, materiais, certificados, perfil e chat com professores.

Acesso liberado após o pagamento No fluxo planejado, o aluno escolhe o curso, entra na conta e faz o pagamento. Após a confirmação, o backend libera o curso para aquela conta e verifica a autorização a cada solicitação de aula, inclusive quando alguém abre o endereço direto.

02 / MINHA CONTRIBUIÇÃO

O que já construí.

Interface pública

Implementei o front-end em HTML, CSS e JavaScript, com barra de navegação, rodapé e cabeçalho com metadados reutilizáveis. Organizei o CSS em um arquivo base e estilos específicos por página.

Identidade visual

Usei o azul-marinho e o dourado do logotipo como ponto de partida para criar a identidade visual do IMB.

Segurança desde a base

Configurei o bloqueio da listagem de diretórios, uma página de erro com status HTTP 404 e validação com proteção antispam no formulário de contato.

Modelagem do banco

Modelei 15 tabelas antes de criar o banco, definindo chaves, índices e relacionamentos.

03 / POR TRÁS DO CÓDIGO

Como desenvolvo o IMB.

  1. Planejo antes de programar. Defino requisitos, escopo, fluxos e modelo de dados antes de criar as telas.
  2. Desenvolvo em etapas. Comecei pelo front-end e organizei o restante em fases, do banco de dados à entrega dos vídeos.
  3. Valido cada mudança. Leio os arquivos para entender como funcionam, testo antes de seguir e renomeio versões antigas antes de removê-las.
  4. Reavalio as escolhas técnicas. Comecei com Laravel, experimentei PHP puro e voltei ao Laravel enquanto o backend ainda estava no planejamento. Nesse momento, a troca exigia pouco retrabalho e fazia sentido para a evolução da plataforma e para o meu aprendizado.
04 / PRÓXIMA FASE

O que vem a seguir.

As próximas etapas incluem autenticação, dashboard do aluno, player de vídeo protegido, pagamentos com liberação automática de cursos, certificados, painel administrativo e publicação.
