# Duda.zip — Portfólio
Portfólio de Maria Eduarda Pereira Santos.

## Arquivos
- index.html: conteúdo e estrutura.
- styles.css: identidade visual, estilos e adaptação para celular.
- script.js: atualização automática do ano no rodapé.
- assets/: imagens utilizadas no site.

## Visualizar
Abra index.html no navegador. Para usar um servidor local, execute nesta pasta:
python3 -m http.server 8000
Depois abra http://localhost:8000.

## Hospedar
Este é um site estático. Não precisa de PHP, banco de dados, instalação de pacotes ou comando de build.
Publique index.html, styles.css, script.js e a pasta assets juntos na pasta pública da hospedagem.
O index.html deve ficar na raiz da publicação, e os nomes e caminhos das imagens devem ser preservados.
Em serviços que solicitam uma pasta de publicação, selecione a pasta que contém index.html.
As fontes do Google Fonts usam conexão com a internet; há fontes alternativas configuradas no CSS.

## Editar
Textos e links ficam em index.html. Cores e tamanhos ficam em styles.css.
O site exportado é independente do acesso privado do ChatGPT Sites: a visibilidade dependerá da hospedagem escolhida.
